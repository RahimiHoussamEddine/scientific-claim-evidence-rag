# Local data dictionary

All data paths below are generated by make fetch and ignored by Git.

| File | Source contents | Expected records | Used for |
|---|---|---:|---|
| data/processed/corpus.jsonl | Document ID, title, abstract sentences, structured flag | 5,183 | Retrieval index and displayed evidence |
| data/processed/claims_train.jsonl | Claim IDs and annotated evidence | 809 | Optional development/error inspection only |
| data/processed/claims_dev.jsonl | Claim IDs and annotated evidence | 300 | Validation metrics |
| data/processed/claims_test.jsonl | Claim IDs and text; labels are not present | 300 | Not scored |
| data/raw/scifact_data.tar.gz | Original AllenAI release archive | 3,115,079 bytes | Checksum-verified source artifact |

The original source uses one claim per JSONL row. An evidence map can be empty for claims labeled NOT_ENOUGH_EVIDENCE. Evidence annotations can include multiple documents and rationale sentence indices. Source documentation and license are in data/source_manifest.json and NOTICE.md.
